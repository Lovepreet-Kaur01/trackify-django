# Todo List Django App 🚀

An advanced Todo List web application built using:

- Django
- Python
- HTML
- CSS
- JavaScript

## Features

- User Authentication
- Add / Edit / Delete Tasks
- Task Completion System
- Search Tasks
- Priority Levels
- Due Dates
- Dashboard Statistics
- Progress Bar
- Dark / Light Mode
- Responsive Design

## Tech Stack

- Python
- Django
- SQLite
- HTML5
- CSS3
- JavaScript

## Installation

```bash
git clone <your-repo-link>

cd TodoList_Web

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
